# ПРОКЛИНАТОР 🔮

Генератор шуточных проклятий. Когда просто «ну и ладно» недостаточно.

**Открыть:** https://irinamarshanskaya-png.github.io/proklinator/

## Что это

Имя → ситуация → сила → «Проклясть» → одно короткое смешное проклятие → отправить другу картинкой 9:16.

Все проклятия безобидные: бытовые неудачи, нелепые совпадения, мелкие раздражения.

## Как устроено

Всё приложение — один файл `index.html`, без сборки и зависимостей. Работает офлайн.

Тексты лежат в массиве `CATEGORIES`: 10 категорий, в каждой 20 ситуаций и 12 проклятий, плюс общие пулы `BY_POWER` по трём уровням силы. Чтобы добавить категорию, достаточно дописать один объект:

```js
{ id:'...', emoji:'...', title:'...', keys:[...], situations:[...], curses:[...] }
```

Мужская и женская формы пишутся альтернацией: `{сказал|сказала}`.
